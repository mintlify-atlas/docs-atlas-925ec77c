Packets are the fundamental units of communication between client and server. The Wirethread network module provides a type-safe packet system with automatic serialization.

## Packet interface

All packets implement the `Packet` interface, which defines the core contract for network messages.

### Interface definition

```java
package com.wirethread.network.packet;

public interface Packet {
    @NotNull
    PacketBound getBound();

    @NotNull
    ConnectionState getConnectionState();

    default boolean isTerminal() {
        return false;
    }
}
```

<ParamField path="getBound" type="PacketBound">
  Returns the bound of this packet (CLIENT_BOUND or SERVER_BOUND)
</ParamField>

<ParamField path="getConnectionState" type="ConnectionState">
  Returns the connection state this packet belongs to
</ParamField>

<ParamField path="isTerminal" type="boolean" default="false">
  Returns true if this is the last packet of the connection
</ParamField>

## Packet bounds

The `PacketBound` enum identifies which side of the connection handles a packet.

### PacketBound enum

```java
public enum PacketBound {
    CLIENT_BOUND,  // Server → Client
    SERVER_BOUND;  // Client → Server

    public PacketBound getOpposite() {
        return switch (this) {
            case CLIENT_BOUND -> SERVER_BOUND;
            case SERVER_BOUND -> CLIENT_BOUND;
        };
    }
}
```

<ResponseField name="CLIENT_BOUND">
  The client receives the server response
</ResponseField>

<ResponseField name="SERVER_BOUND">
  The server receives the client request
</ResponseField>

### Methods

<ResponseField name="getBound" type="int">
  Returns the ordinal + 1 as an integer identifier
</ResponseField>

<ResponseField name="getOpposite" type="PacketBound">
  Returns the opposite packet bound
</ResponseField>

## Packet format

The `PacketFormat` record represents the header of a network packet.

```java
public record PacketFormat(int packetSize, int packetId) implements Packet {
    public static final Type<PacketFormat> SERIALIZER = new Type<>() {
        @Override
        public PacketFormat read(@NotNull ByteBuf buffer) throws IOException {
            return new PacketFormat(
                Numbers.VAR_INT.read(buffer),
                Numbers.VAR_INT.read(buffer)
            );
        }
    };
}
```

<ParamField path="packetSize" type="int">
  The size of the packet in bytes
</ParamField>

<ParamField path="packetId" type="int">
  The unique identifier for this packet type
</ParamField>

<Info>
  Packet format follows the [Minecraft Java Edition protocol](https://minecraft.wiki/w/Java_Edition_protocol/Packets#Packet_format) specification.
</Info>

## Creating custom packets

To create a custom packet:

<Steps>
  <Step title="Define the record">
    Create a record implementing the appropriate packet interface
    ```java
    public record MyCustomPacket(
        String data
    ) implements ServerBoundPacket.Play {
    }
    ```
  </Step>
  
  <Step title="Add serializer">
    Define a static `SERIALIZER` field with read/write logic
    ```java
    public static final Type<MyCustomPacket> SERIALIZER = new Type<>() {
        @Override
        public MyCustomPacket read(@NotNull ByteBuf buffer) throws IOException {
            return new MyCustomPacket(Primitives.STRING.read(buffer));
        }
        
        @Override
        public void write(@NotNull ByteBuf buffer, MyCustomPacket value) throws IOException {
            Primitives.STRING.write(buffer, value.data());
        }
    };
    ```
  </Step>
  
  <Step title="Register the packet">
    Add the packet to the appropriate packet registry
  </Step>
</Steps>
