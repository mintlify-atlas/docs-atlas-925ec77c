## What is Wirethread?

Wirethread is an open source Minecraft server framework that provides a complete and easy-to-use API for building custom Minecraft servers. Built from the ground up, Wirethread offers a modern alternative to traditional server implementations with a focus on modularity, performance, and developer experience.

Unlike Spigot, Paper, or other servers, Wirethread is **not compatible** with existing server plugins. Instead, it provides a fresh architectural approach designed to make server development straightforward and powerful.

## Why choose Wirethread?

Wirethread aims to be a tool for developing cross-platform servers that support all game versions with:

- **Modular and extensible** architecture that grows with your needs
- **Complete API** covering all server functionality
- **Easy to use** with modern Java patterns and clear abstractions
- **Cross-edition support** for both Java and Bedrock editions
- **Native features** that traditionally require third-party plugins

The framework equips developers with modern and powerful tools that allow them to program more compact and efficient logic units.

## Architecture overview

Wirethread is organized into modular components:

- **wirethread-core** - Core abstractions, registries, coordinates, and game logic
- **wirethread-network** - Network protocol implementation and packet handling
- **wirethread-plugin** - Plugin system for extending server functionality
- **wirethread-server** - Main server implementation with thread management

<Tip>
  Each module can be used independently or extended to create custom server implementations.
</Tip>
